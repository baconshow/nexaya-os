# Propostas

Propostas comerciais do ateliê (fictício), uma por cliente, sempre a partir do
[modelo](modelo-proposta.md). A skill `proposta-comercial` escreve o rascunho;
a Ana revisa preço e prazo e envia.

## Convenção de nomes

`AAAA-MM-tipo-de-negocio.md`, por exemplo `2026-09-padaria.md`. Nunca o nome
de uma pessoa no arquivo.

## Estado

O estado das propostas em andamento está no [PROXIMO.md](PROXIMO.md).
