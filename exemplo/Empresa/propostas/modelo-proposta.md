# Modelo de proposta

Estrutura fixa, nesta ordem. Frases curtas, sem jargão.

1. **O problema, nas palavras do cliente.** Uma frase.
2. **O que vou entregar.** Lista fechada de páginas do painel, com uma linha
   cada.
3. **O que não está incluído.** Pelo menos dois itens, para ninguém se
   surpreender depois.
4. **Como trabalhamos.** Uma reunião para entender os dados, uma entrega, uma
   reunião de validação e um ajuste.
5. **Prazo e investimento.** Preenchidos pela Ana.
6. **Próximo passo.** Uma frase dizendo o que o cliente faz para começar.

Frases-padrão:

- "O painel mostra os números que você já tem, organizados para decidir mais rápido."
- "Ajustes depois da validação entram numa nova proposta."
