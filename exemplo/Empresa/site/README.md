# Site do ateliê

Site de uma página do ateliê da Ana (fictício): o que o ateliê faz, três
exemplos de painel e um formulário de contato que abre o e-mail da pessoa
(sem backend). HTML e CSS puros, em `public/`.

## Como rodar

Suba o app `site-atelie` pelo painel (se houver o Nexaya OS Pro), ou rode
`python -m http.server 5520 --bind 127.0.0.1` dentro de `public/` e abra
`http://127.0.0.1:5520`.
