# Curso de estatística

Curso livre de estatística em oito módulos, feito à noite. As notas de cada
aula viram uma página HTML em `notas/`, com os exercícios resolvidos.

## Módulos

1. Estatística descritiva — concluído.
2. Probabilidade — concluído.
3. Distribuições — concluído.
4. Inferência — em andamento.
5. Regressão.
6. Séries temporais (o que mais interessa à dissertação).
7. Experimentos.
8. Bayesiana.

## Como ver as notas

Suba o app `notas-estatistica` pelo painel (se houver o Nexaya OS Pro), ou rode
`python -m http.server 5530 --bind 127.0.0.1` dentro de `notas/`.
