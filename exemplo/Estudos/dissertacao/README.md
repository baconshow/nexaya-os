# Dissertação

Previsão de demanda semanal de livros por categoria, comparando um modelo
sazonal simples com um modelo de gradiente. Os dados são da livraria
(fictícia), agregados e anonimizados.

## Estrutura

1. Introdução — escrita, revisada pelo orientador.
2. Revisão de literatura — escrita; faltam dois fichamentos.
3. Dados e método — em escrita.
4. Resultados — depende do capítulo 3.
5. Conclusão.
