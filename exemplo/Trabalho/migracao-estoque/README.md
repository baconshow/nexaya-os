# Migração do estoque

Mapeamento das planilhas de estoque das seis lojas (fictícias) para o sistema
novo da livraria. O trabalho é um de-para de colunas e de códigos de categoria,
mais uma lista de inconsistências para a gerência resolver antes da carga.

## Estado das partes

- **De-para de colunas:** feito para as planilhas de quatro lojas.
- **Códigos de categoria:** depende do dicionário de campos do sistema novo.
- **Carga:** fora do escopo da Ana; quem carrega é o fornecedor.

## Onde está cada coisa

- O de-para mora numa planilha na pasta de rede da livraria, acessível só do
  computador do trabalho.
- Esta pasta guarda só as notas e o estado (`PROXIMO.md`).
